# 新增功能：

添加引导点以后，如果引导曲线编辑器未关闭，按键盘+-号可以快速让上次添加的点沿中心线方向移动（和编辑器中的+-号左右相同且走相同的路线）  
引导曲线编辑器 Edit按钮汉化，里面添加拾取按钮，可以从模型上直接拾取点，并更新。这里设置的坐标也视为“上次添加”的点，可以使用+-号键  

修复两种特殊发型

## 发束钻孔（工作量较大）：
发束执行分割时，发束之间会相互布尔（目前已有），
计算出所有在出现切割事件时新出现的面（即两个模型之间的连接面），作为addon的mesh，可以切换是否显示，但是后续不参与任何碰撞。
添加钻孔路径以后：
允许用户指定一个半径，然后在连接面、底模、发束本体（此时发束变为可鼠标拾取的状态）上选择点，选择的点也像发束的引导点一样可以使用+-号。
点之间会用设置的半径的圆进行放样（不需要插值，这个mesh也作为附加件渲染）
钻孔路径可以有多个，允许设置命名，有独立的半径，注意发束的mesh命名规则要加前缀，这个也要加，避免冲突。
真正执行切割时，每一根发束都会先减去这个mesh，再执行后续步骤。
