# 新增功能：
引导曲线编辑器中新增反转整条线所有点顺序的按钮

发束新增改名功能，改的是uuid的位置，并且渲染器中也创建新的key进行move操作

导出图片时可以选择把发束引导线也导出，
此模式时可以选择用颜色区分发束并在上面标上名字（参考`D:\project\kigstudio\tools\kimi-agent\hair_guides.py`的形状）  

特殊引导点：  
发束首尾允许有特殊的的隐藏引导点，用两个单独的数组保存（这两个数组会进入json），发束放样和添加宽度向量时参与处理，但是它本身无法被编辑，导出图片时不显示，正交编辑器ui中不显示，但是3d模型编辑器中显示（包括曲线区域。隐藏区域曲线和十字叉用灰色来区分），加在上面的宽度向量和原来保持不变，这片区域供专用函数使用。  

发根：  
在头顶坐标（语义坐标系）存在时，在引导线编辑器顶部多一个勾选框，勾选时，添加一个隐藏引导点到发束首，位置在从外沿头顶方向的向量向中心发射，在底模上的第一个碰撞点。曲线勾选时，清空发束首的隐藏引导点。这个状态会保存入json
