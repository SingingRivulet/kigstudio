# 参考几何体：  

添加参考几何体功能，不属于任何节点，在文件tab中可以选择显示哪个，可以设置当前节点是否允许被鼠标捕获  
刷选参考几何体，自动计算guide_curve和宽度  

# 自动设置发束宽度：  

需要指定发际线平面的位置：api中直接利用接口提交的y坐标，ui中通过选择三个点指定。
找到每根发束引导线与发际线平面相交的点，计算每个交点离最近的交点的距离，将当前位置的宽度向量长度设置为这个距离（这个向量是虚拟的，实际不存在），然后对这个虚拟向量两侧的宽度向量进行插值，
然后从这个位置往两端（起点和终点）一路插值，在两端收束到一个极小值，形成一个纺锤型
如果一根发束与平面的交点超过一个，就不进行处理。
