# 参考几何体：  

添加参考几何体功能，不属于任何节点，在文件tab中可以选择显示哪个，可以设置当前节点是否允许被鼠标捕获  
刷选参考几何体，自动计算guide_curve和宽度  

# 发束正交投影编辑模式：

按钮在附加件编辑器添加发束右边，点击后弹出一个窗口
窗口里面有两个需要设置的控件：
第一个是需要指定一个向量（通过点击模型上一个点，将它与中心点的连线作为向量，或者直接选择六视图中的一个），无论哪种方式，都会渲染向量进行预览。  
第二个是设置viewport的边长
确认以后，对当前的底模进行渲染一次（非实时渲染，输出两张图片，一张是用来看的，一张是坐标图，用来拾取），弹出一个新的imgui窗口，里面是底模图片。这个窗口顶部有一个按钮，可以选择一张本地图片。选择以后顶部出现一个勾选框，勾选以后可以拖动和缩放这张图（便于和底模重合）。右边有一个拖动条，可以设置载入的图片和底模图片混合比例。
未勾选时，鼠标如果在这个窗口中的模型部分时，会直接按当前的位置覆盖全局的拾取参数（3d模型那边也会看到原来的红色光标改变），如果点击这个模型，会视为在3d模型上点击
这个窗口中也会实时预览每根发束的路线和宽度向量，有两个勾选框设置是否显示这两个预览。
