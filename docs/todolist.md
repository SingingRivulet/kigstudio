# 参考几何体：  

添加参考几何体功能，不属于任何节点，在文件tab中可以选择显示哪个，可以设置当前节点是否允许被鼠标捕获  
刷选参考几何体，自动计算guide_curve和宽度  

## 修改  

前后左右不要按绝对坐标系来，改为按“坐标系配置”中的设置（棕色箭头与等腰三角形）来确定，且摄像机上方使用配置的北极方向。  

自动计算正交投影编辑的视口大小的默认值，为坐标系配置中演示球大小的1.5倍  

新增接口，可以从外部读取或者提交引导线到2d图片上。修改D:\project\kigstudio\tools\kimi-agent （该目录为上一次ai成功运行后生成的脚本文件和临时文件），让它可以直接操作操作kigstudio主程序，并且提交2d坐标回来，无需用户手动截图上传图片和复制坐标回程序。  
原prompt:  
```
@图片路径 这是一张动漫图片，头发建模由多根发束放样组成，帮我绘制一下每一根发束的放样引导线坐标，做完以后记得检查一下是否与发束中心重合
```
