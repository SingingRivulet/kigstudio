# 新增功能：

附加件编辑器图片增加jpg支持、中文路径支持

附加件编辑器引导线高亮改为红色，鼠标放到附加件编辑器相应栏目上时，对应的发束引导线就变红（之前要打开引导线编辑器以后才变黄），并且引导线变红时，正交编辑器中也变红  

3d模型视图中，引导曲线上的点不再使用十字叉，而是改为箭头，按顺序，指向当前切线方向（隐藏引导点也要更改）  

引导曲线编辑器中允许对某个点出现拾取，鼠标放在引导曲线编辑器某个点上时，相应的点变红

发根：  
附加件编辑器发束模式顶部加入新按钮“发根编辑”，点击以后弹出窗口。注意不要设置与其他窗口互斥。
打开以后会用三个紫色的圈渲染出发根点，半径和中心点的圈相同。
里面可以勾选让哪些发束启用发根，有一个按钮可以更新所有发束的发根
允许设置发根点往中心点移动一定距离

正交编辑器隐藏所有点都被遮挡的线
